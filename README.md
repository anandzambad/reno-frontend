# Reno V2 Frontend

Modern frontend for Reno V2.

## Target stack

- Next.js (App Router)
- React
- TypeScript
- REST API integration
- Docker
- GitHub Actions

## Architecture

The application will use a feature-oriented structure. UI concerns stay in the frontend while business rules and persistence remain in the backend.

## Migration

This repository is the modern frontend target for the legacy Reno application. Modules will be migrated incrementally after the legacy application and MySQL schema are mapped.
